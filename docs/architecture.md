# Архитектура

## Поток данных

1. `dataset.py` читает VCF/VCF.GZ, TSV и ZIP; извлекает варианты, генотипы и доступные аннотации.
2. `knowledge.py` загружает локальные, проверяемые человеком словари.
3. `pipeline.py` — единственный оркестратор: нормализует фенотип, вызывает экспертов, вычисляет итоговый статус и передаёт результат на отчёт.
4. `experts.py` содержит три детерминированных правила: phenotype, molecular и inheritance.
5. `ranking.py` объединяет три шкалы по конфигурации `config/ranking.json`.
6. `reporting.py` сериализует полный результат в HTML, Markdown, JSON и TSV.

## Контракт экспертов

Каждый эксперт возвращает `ExpertResult`:
- `score` от 0 до 1 — внутренняя экспертная шкала;
- `evidence` — человекочитаемые основания/ограничения;
- `matched_hpo` — совпавшие HPO ID;
- `matched_variants` — варианты, рассмотренные модулем.

### Phenotype expert

Сопоставляет HPO ID входного фенотипа с профилем заболевания из `knowledge.json`. Сейчас это точное сопоставление в небольшой демонстрационной базе. Онтологическое сходство по графу HPO и информационное содержание пока не рассчитываются.

### Molecular expert

Выводит варианты в генах-кандидатах и доступные consequence/ClinVar annotation. В версии 0.2.0 его численный вклад всегда равен нулю: автоматическое суммирование генного совпадения, consequence или свободного текста `CLNSIG` было бы чрезмерно сильным выводом. Для включения положительного балла требуется курируемая проверка точного ALT, disease, transcript/HGVS и ClinVar review status.

### Inheritance expert

Проверяет только ограниченную совместимость генотипа с AD/AR. Он не выводит de novo, семейную сегрегацию или фазу. Несколько строк варианта не означают, что два причинных аллеля находятся в trans.

## Оркестратор и оценки

По умолчанию:
- phenotype: 0.55;
- molecular: 0.35;
- inheritance: 0.10.

Итог — взвешенная сумма экспертных шкал. Это приоритет для просмотра, не вероятность. Веса и порог candidate читаются из JSON-конфигурации, а не подбираются LLM.

## Границы

Прототип не выполняет внешнюю VEP-аннотацию, полный импорт HPO/ClinVar, CNV/SV calling, покрытие, фазировку, pedigree inference или ACMG/AMP классификацию. Источники в карточках — научные справочники и поиск литературы по заболеванию/гену; публикация по конкретному варианту должна подтверждаться отдельно.
